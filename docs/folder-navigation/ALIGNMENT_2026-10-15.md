# Navigation alignment and reading contrast

The navigation uses the same centred 80rem maximum column as the header bar and page layout. At desktop widths of 1100px and above, PROJECT 100 uses seven equal columns; FIT PROTOCOL uses six equal columns over two rows. Smaller screens keep one contained swipe row. Every original destination remains present.

Folder labels use primary text colour at 750 weight, with solid, darker category spines in light mode and brighter category spines in dark mode. Supporting text and neutral borders have stronger shared tones. Browser checks now require matching header/navigation edges, no desktop horizontal overflow, equal desktop widths and at least 7:1 computed label contrast.
