# Folder navigation design / 15 October 2026

The shared source stylesheet is assets/css/site.css. Published HTML contains each navigation destination and its data-folder colour family; navigation does not depend on JavaScript to insert links. The shared site script only centres the current folder after font loading and resizing.

The same visual grammar is authored in the existing component definitions in site.css, hud.css, mobile-rail.css and kinetics.css: squared bodies, small angled cuts, a coloured leading edge, neutral readable text, and active/open emphasis confined to that edge. Existing content, source images, tables and data charts are preserved. Folder and menu semantics remain native links, buttons and details/summary.

The source-preservation report records the original page-content comparison for all 55 edited pages. The browser report covers every header at phone and desktop widths plus representative Chromium, Firefox and WebKit checks, light/dark themes, keyboard traversal, JavaScript-disabled navigation, section folders and download browser interactions. Screenshots in this folder provide visual review evidence.
