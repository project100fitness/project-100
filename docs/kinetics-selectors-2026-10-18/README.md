# Illustrated programme selectors and background media

The programme index uses the existing anatomical illustration assets and orange folder style. Programme anchors expose a persistent current-section state (`aria-current=location`), visible directional actions, keyboard focus and hover feedback. They scroll to existing content; sections are not hidden. Day links are outbound session cards with numbered badges, muscle labels, the twelve-exercise count and an explicit Open session action. They intentionally do not claim a selected-tab state.

The oversized full-body bundle diagram is replaced by a native details disclosure. Its summary identifies HPYGN + Tribe and the per-side nominal rating. Expansion retains the matched left/right pairs, threaded bar and eyelet information, combined nominal rating, system distinction and trainer-managed resistance note. The folder headers retain compact clipped tabs and a prominent illustrated-guide button; all setup galleries and movement families remain present.

Scoped tokens: `--kin-accent` for orange edges, `--kin-action` (#b83a00, the existing light-theme action orange) for white-on-orange selected choices and controls, and the existing paper/ink/soft tokens for theme backgrounds. Current state is conveyed by fill and ARIA as well as border colour. Images are decorative because the adjacent link text names each destination. Native details supports keyboard activation without additional script.

Background videos share muted inline playback, viewport pause/resume, page visibility handling and a direct play/pause control. Reduced motion defaults to a poster; explicit Play opts into that clip. A Kinetics hero clip uses the existing bands-session-004 asset; the original bands-in-use banner remains. The homepage shade is lighter, videos no longer use translucent layers or masks, and text/shade/video stacking is explicit. Three mobile copies are derived from the existing clips using baseline H.264; desktop originals remain unchanged. Background dimensions are calculated from the intrinsic video ratio and banner size, avoiding the Android crop failure without changing page layout.

Validation: source/publication checks cover 65 root pages and 5,004 local links, all current book references, five direct day links, two illustrated choices and retained setup facts. Browser geometry checked at 320, 360, 412, 768 and 1440 pixels with no page overflow or clipped selector labels. Desktop clip playback and manual play under reduced motion verified. Android layout was checked at 360px and a fresh 56-page 412px pass was run after the shared-media change. Isolated Android tests identified corruption with the original encoding and a blank surface when portrait footage was vertically cropped using object-fit:cover. Baseline encoding plus proportional element sizing produces visible decoded frames in the actual Android Kinetics hero; desktop decoded frames are also visibly present. Physical-device video rendering remains unverified.
