# Source-owned website design update / 19 October 2026

## Scope

All 117 pages using the shared site shell now declare their design profile and section roles in their HTML. The authored roles distinguish training/actions, reference, data and general content. Shaded folder navigation remains the baseline. Supporting material uses one muted teal alongside the orange brand, neutral reading surfaces, fine keylines and faint technical grids. The component inventory is in `page-roles.json`.

The temporary `section-accents.css` prototype was discarded before release. No links to it are shipped. Changes are maintained inside the existing component stylesheets, beside the definitions they extend. Reference callouts, accordions, tables and file cards use explicit source classes. The analysis entry's presentation moved from its inline style into its named component.

Training folders now use their own authored container, `p100-session-folders`, and shared rendering/selection logic was updated with it. This removes the old carousel selector collision responsible for selected text losing contrast in light mode. Planned exercise counts and prescriptions did not change.

## Verification

- 351 browser layout checks across all 117 pages: 360px dark, 360px light and 1440px dark. No horizontal page overflow, broken loaded local images, clipped headings or JavaScript errors were found.
- 25 training layouts across five widths and all five training days: folder toggle, complete planned rows, shared exercise detail, Chest collection, checkbox selection, reload persistence, print preview, PDF download and clearing selection passed.
- LDPlayer Android touch tests at 360px and 412px across all five training days passed. Folder toggle, selection and shared detail opening/closing were tested with touch input.
- Existing publication/source checks and grip metadata consistency checks passed; all 114 distinct selectable exercises assembled successfully in the existing PDF export regression.

This release changes interface presentation and component ownership. Exercise artwork, anatomical claims, source-evidence status, original manuals, prescribed sessions and PDF content remain as previously published. Browser and metadata checks do not establish clinical or anatomical certification.
