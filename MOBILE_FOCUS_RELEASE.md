# Mobile content focus and continuous galleries

Mobile galleries now show two adjacent preview widths, including training, meals, gear photos and journey chapters. Cards retain their media, dates, titles and platform links, while repeated generic recipe/source taglines and engagement counters no longer occupy the previews. Redundant folder-opening instructions, rail headings, promotional eyebrows and duplicate walkthrough headings are removed. Primary horizontal and secondary vertical navigation remain intact, with a slightly narrower mobile rail and compact section spacing.

The shared carousel controller moves content slowly right to left by default at 14 px/second, with seamless copies for two-way looping. Horizontal swipes, wheel input and arrow navigation set the subsequent direction. Motion pauses during pointer input, hover, keyboard focus and embedded playback; touch/wheel navigation resumes after a short reading interval. Offscreen/hidden rows and reduced-motion preferences stop automatic movement. Dynamically filtered rows receive the same controller and dispose of listeners/frames when rebuilt. Two older interval-based controllers were removed.

`apply_mobile_focus.py` runs last in the build so regenerated pages retain the copy/layout changes. Nutrition formulas, substantive protocol/safety content and the selected artwork remain in place. Shortened platform labels retain their links. Mobile repeated footer navigation is hidden because primary and file navigation already provide those routes.

Validation: 176 page/viewport overflow and two-preview checks; continuous default motion; reversed wheel and swipe direction; automatic resume; reduced-motion changes; dynamic filter lifecycle; two-way boundary wrapping, resize, history and keyboard video playback. Site audit covers all 53 HTML pages. Focused MAIN navigation and moved-record/image checks pass with only the explicitly authorized boilerplate and action-label exclusions. Four mobile preview pages and the landing page were visually reviewed.
