# PROJECT 100 text reference package

Edition 18 October 2026. Website source baseline e29360e66b546935a09fb2aaa1f2ed86e0c691a8.

Read the Master Analysis Reference for the complete evidence and analysis, the Encyclopedia Update for chapter integration, and the Guidebook Update for a concise practical companion. PDFs are searchable and have section bookmarks. The master has a linked table of contents. Markdown files are the editable text sources.

No illustrations or prescribed exercise sets are included. Individual source passages and movement findings remain as analytical evidence. The current illustrated exercise books remain separate.

The JSON and CSV files support reuse in future guidebooks. Evidence classes, serving basis and unresolved inputs must remain attached to any reused claim. The nutrition figures are website model estimates or attributed caption records, not newly measured intake. The video review remains the frozen reviewed-recording scope, not an exhaustive new review of every file.

The older full Encyclopedia and Guidebook PDFs are preserved as archives. These two updates are companion supplements, not complete replacements of every older chapter.
