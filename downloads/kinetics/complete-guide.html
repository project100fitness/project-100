Day 1 / Chest, shoulders + triceps

01

Supported single-arm chest press

Chest / 2 planned sets / 8-12 each side

START / handle beside chest FINISH / controlled press

SETUP / Stable box; rear anchor near chest height.

MOVE / Press forward without leaning or twisting.

RETURN / Stop before elbow lock; return within a comfortable arc.

MAIN / RED

Pectoralis major: moves the upper arm forward and across the chest.

SECONDARY / BLUE

Triceps extend the elbow; anterior deltoid assists. Scapular muscles guide the shoulder blade.

SUPPORT / GREEN

Trunk muscles resist rotation; the box and planted feet stabilize the pelvis and legs.

02

Single-arm side-line chest and shoulder control

Chest / 1 planned set / 8-12 controlled repetitions

POSITION A → POSITION B

SETUP / Stand in a staggered base with one side-line grip beside the shoulder.

MOVE / Control the working arm while the torso and free arm change position.

RETURN / Return slowly without turning the grip into a separate wrist attachment.

MAIN / RED

Pectoralis major and front deltoid control the working upper arm against the side-rear line.

SECONDARY / BLUE

Shoulder, elbow and forearm muscles control the shown arm path and retained grip.

SUPPORT / GREEN

Trunk and hip muscles steady the shown support contacts.

03

Standing shared-grip low-front arm raise with torso hinge

Shoulders / 1 planned set / 8-12 controlled repetitions

POSITION A → POSITION B

SETUP / Hold the shared low-front grip with both hands; knees softly bent.

MOVE / Raise the hands forward as the torso returns toward upright.

RETURN / Lower the grip slowly as the torso hinges forward.

MAIN / RED

Front deltoids guide the arm raise; hip extensors help bring the torso toward upright.

SECONDARY / BLUE

Triceps controls the extended elbows; forearm muscles maintain the shared grip.

SUPPORT / GREEN

Trunk muscles steady the spine and the planted feet support the stance.
