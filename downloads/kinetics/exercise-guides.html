PLYOSOFT box-supported one-arm row

Band technique

START / softly extended arm FINISH / controlled pull

GRIP / CONTACT / Neutral handle grip. Palms face inward relative to the working arm; keep wrists in line with forearms.

SETUP / Stable box; one handle on a front line near hand height.

MOVE / Draw the elbow toward the lower ribs without twisting.

RETURN / Lower slowly to a softly extended arm.

MAIN / RED

Latissimus dorsi: draws the upper arm back toward the trunk.

SECONDARY / BLUE

Rhomboids and middle trapezius control the shoulder blade; rear deltoid and elbow flexors assist the pull.

SUPPORT / GREEN

Abdominals and spinal stabilizers resist rotation. Hips, thighs and ankle muscles steady both feet; the other arm supports the torso.

Supported single-arm chest press

Band technique

START / handle beside chest FINISH / controlled press

GRIP / CONTACT / Neutral handle grip. Palms face inward relative to the working arm; keep wrists in line with forearms.

SETUP / Stable box; rear anchor near chest height.

MOVE / Press forward without leaning or twisting.

RETURN / Stop before elbow lock; return within a comfortable arc.

MAIN / RED

Pectoralis major: moves the upper arm forward and across the chest.

SECONDARY / BLUE

Triceps extend the elbow; anterior deltoid assists. Scapular muscles guide the shoulder blade.

SUPPORT / GREEN

Trunk muscles resist rotation; the box and planted feet stabilize the pelvis and legs.

Seated straight-bar pressdown

Band technique

START / elbows bent FINISH / soft elbow extension

GRIP / CONTACT / Overhand / pronated grip. Retain the illustrated overhand grip with thumbs wrapped and wrists aligned. Palm direction follows the arm position.

SETUP / Stable box; high front line and straight bar.

MOVE / Extend the elbows while keeping upper arms nearly still.

RETURN / Bend the elbows slowly; keep the bar clear of the face.

MAIN / RED

Triceps brachii: straightens the elbow.

SECONDARY / BLUE

Forearm muscles steady the grip and wrist; shoulder muscles hold the upper arms beside the torso.

SUPPORT / GREEN

Trunk muscles hold a quiet seated posture; both feet and the box provide support.

Seated single-leg band curl

Band technique

START / heel forward FINISH / heel drawn back

GRIP / CONTACT / Ankle-cuff resistance. Resistance attaches to the illustrated ankle cuff; the hands provide support only.

SETUP / Stable box; low front line and approved ankle cuff.

MOVE / Draw the heel back by bending the knee.

RETURN / Return slowly; keep the heel path clear of the box.

MAIN / RED

Hamstrings bend the knee, drawing the heel back.

SECONDARY / BLUE

Gastrocnemius can assist knee flexion. Ankle-positioning muscles hold the foot position; hip muscles keep the thigh aligned.

SUPPORT / GREEN

box, opposite planted foot and trunk muscles steady the pelvis. The working thigh stays supported.

Seated neutral-grip curl

Band technique

START / soft elbow extension FINISH / controlled curl

GRIP / CONTACT / Neutral handle grip. Palms face inward relative to the working arm; keep wrists in line with forearms.

SETUP / One light handle line from a secure low front anchor.

MOVE / Bend the elbow without swinging or leaning back.

RETURN / Lower slowly to a softly extended elbow.

MAIN / RED

Brachialis, biceps brachii and brachioradialis bend the elbow.

SECONDARY / BLUE

Forearm muscles hold a neutral grip; shoulder muscles steady the upper arm.

SUPPORT / GREEN

box, feet and trunk control keep the pelvis and torso still.

Box-kneeling elbow extension

Band technique

START / elbows bent FINISH / forward extension

GRIP / CONTACT / Neutral handle grip. Palms face inward relative to the working arm; keep wrists in line with forearms.

SETUP / Both knees on the box; paired high rear lines.

MOVE / Extend the elbows to move the hands forward.

RETURN / Return hands near the head under control.

MAIN / RED

Triceps brachii extends the elbows. The recorded torso fold is an additional movement, not isolated triceps work.

SECONDARY / BLUE

Shoulder muscles control upper-arm position; forearm muscles stabilize the handles.

SUPPORT / GREEN

Trunk muscles control the inclined torso. Both knees contact the padded box and form the support base.

Floor-kneeling overhead band extension

Band technique

START / elbows flexed FINISH / handles overhead

GRIP / CONTACT / Neutral handle grip. Palms face inward relative to the working arm; keep wrists in line with forearms.

SETUP / Both knees on the floor; one rear-line handle per hand.

MOVE / Extend the elbows to raise both handles overhead.

RETURN / Bend elbows and return hands behind the head.

MAIN / RED

Triceps brachii extends the elbows as the handles move overhead.

SECONDARY / BLUE

Shoulder muscles steady the upper arms; forearm muscles maintain each handle grip.

SUPPORT / GREEN

Both knees and shins contact the floor. Trunk and hip muscles maintain the kneeling posture.

Supported low-front band curl

Band technique

START / elbow softly open FINISH / controlled low-anchor curl

GRIP / CONTACT / Underhand / palms-up grip. Maintain the illustrated palms-up grip and aligned wrists; bend at the elbow, not the wrist.

SETUP / Low front anchor; free palm on a stable support; palm-up grip.

MOVE / Curl upward away from the low anchor; keep the upper arm steady.

RETURN / Lower slowly without bending the wrist or locking the elbow.

MAIN / RED

Biceps brachii, brachialis and brachioradialis flex the working elbow.

SECONDARY / BLUE

Forearm muscles maintain grip; shoulder muscles control the upper arm. The free arm supports the torso.

SUPPORT / GREEN

Abdominal, spinal and hip stabilizers control the incline. Both feet and the support hand form the base.

Training illustration uses a low front anchor so the band resists upward elbow flexion. The original high-front recording remains source evidence; this is not a claim that it was filmed with a low anchor.

Standing shared-handle overhead extension

Band technique

START / handle behind head FINISH / handle overhead

GRIP / CONTACT / Two-hand shared grip. Both hands retain the shared attachment. Keep each wrist aligned; this is not two independent handles.

SETUP / Both hands share one handle; two tubes run to low rear.

MOVE / Extend both elbows to move the shared handle overhead.

RETURN / Bend both elbows; return the handle behind the head.

MAIN / RED

Triceps brachii extends both elbows as the shared handle moves overhead.

SECONDARY / BLUE

Shoulder muscles control upper-arm position; forearm muscles hold the shared grip.

SUPPORT / GREEN

Trunk and hip stabilizers maintain the standing posture. Both feet form the base in the illustrated version.

Band technique

GRIP / CONTACT / Neutral handle grip. Palms face inward relative to the working arm; keep wrists in line with forearms.

SETUP / Both knees on the floor; two handles from high front.

SETUP / Short bar; paired side lines near waist/lower-chest height.

MOVE / Extend the elbows to press the bar toward the thighs.

RETURN / Let the bar rise slowly as the elbows bend.

MAIN / RED

SECONDARY / BLUE

SUPPORT / GREEN

Shoulder band-bar squat

Band technique

START / standing FINISH / partial squat

GRIP / CONTACT / Overhand / pronated grip. Retain the illustrated overhand grip with thumbs wrapped and wrists aligned. Palm direction follows the arm position.

SETUP / Padded bar across upper back; paired low side/rear lines.

MOVE / Bend hips and knees into a controlled partial squat.

RETURN / Extend hips and knees toward standing.

MAIN / RED

Quadriceps and hip extensors contribute to standing from the squat.

SECONDARY / BLUE

Hamstrings and spinal extensors assist hip and trunk control; shoulder and arm muscles stabilize the bar.

SUPPORT / GREEN

Abdominal muscles stabilize the torso, with feet planted on the floor. Ankle and calf muscles control the base.

Standing alternating low-front curl

Band technique

START / both handles low FINISH / one elbow flexed

GRIP / CONTACT / Underhand / palms-up grip. Maintain the illustrated palms-up grip and aligned wrists; bend at the elbow, not the wrist.

SETUP / Two independent handles; crossed low front lines.

MOVE / Curl one handle; keep the other low, then alternate.

RETURN / Lower the working handle before curling the other.

MAIN / RED

Biceps brachii, brachialis and brachioradialis bend the elbow.

SECONDARY / BLUE

Forearm muscles steady the grip; shoulder muscles maintain upper-arm position.

SUPPORT / GREEN

Trunk and hip muscles steady the standing posture; both feet form the base.

Standing Pilates bar hip hinge

Pilates-kit variation / Band technique

START / hip hinge FINISH / upright

GRIP / CONTACT / Overhand / pronated grip. Retain the illustrated overhand grip with thumbs wrapped and wrists aligned. Palm direction follows the arm position.

SETUP / Secure both foot loops under the shoe arches; connect two matched tubes to each bar end.

MOVE / Hinge the hips back with soft knees, keeping the bar close to the legs.

RETURN / Drive through the feet and extend the hips; keep the arms long.

MAIN / RED

Gluteals and hamstrings extend the hips as the torso returns upright.

SECONDARY / BLUE

Spinal extensors maintain the shape of the back; forearms steady the bar.

SUPPORT / GREEN

Abdominal muscles brace the trunk while both feet support the stance.

Standing Pilates bar overhead press

Pilates-kit variation / Band technique

START / bar at shoulders FINISH / controlled press

GRIP / CONTACT / Overhand / pronated grip. Overhand bar grip; palms face forward at the shoulder rack and through the press. Keep wrists stacked over forearms.

SETUP / Secure the foot loops; connect matched tube pairs through the adjustable bar straps.

MOVE / Press the bar upward from the front of the shoulders without arching the back.

RETURN / Lower slowly to the starting position; use a range set with your trainer.

MAIN / RED

Deltoids raise the upper arms during the overhead press.

SECONDARY / BLUE

Triceps extend the elbows; scapular muscles guide the shoulder blades.

SUPPORT / GREEN

Abdominal and hip muscles keep the torso stacked over the planted feet.

Bent-over Pilates bar row

GRIP / CONTACT / Overhand / pronated grip. Retain the illustrated overhand grip with thumbs wrapped and wrists aligned. Palm direction follows the arm position.

RETURN / Extend the arms slowly without changing the torso angle.

MAIN / RED

Standing Pilates-handle lateral raise

Pilates-kit variation / Band technique

START / hands beside thighs FINISH / arms raised

GRIP / CONTACT / Angled / semi-pronated grip. Angled handle grip; palms generally down, thumbs slightly forward. Keep wrists straight without a forced thumb-down twist.

SETUP / Use the kit handles and foot loops, with two matching tubes on each independent side.

MOVE / Raise the handles out to the sides to a comfortable height, with elbows softly bent.

RETURN / Lower slowly without leaning or shrugging; stay within the agreed range.

MAIN / RED

Middle deltoids raise the upper arms out to the sides.

SECONDARY / BLUE

Supraspinatus and scapular muscles help guide the shoulder movement.

SUPPORT / GREEN

Abdominal muscles steady the trunk while both feet support the stance.

Standing Pilates bar torso rotation

Pilates-kit variation / Band technique

START / centred FINISH / small torso turn

GRIP / CONTACT / Overhand / pronated grip. Retain the illustrated overhand grip with thumbs wrapped and wrists aligned. Palm direction follows the arm position.

SETUP / Secure both foot loops and match the tube pairs; hold the bar just below chest height.

MOVE / Turn the upper torso through a small comfortable arc while the pelvis faces forward.

RETURN / Return to centre slowly, then change sides; avoid forcing the twist.

MAIN / RED

Oblique abdominal muscles guide the small, controlled torso rotation.

SECONDARY / BLUE

Shoulder and arm muscles maintain the held bar position.

SUPPORT / GREEN

Hip and gluteal muscles steady the pelvis over the planted feet.

Standing two-arm band chest press

Added band technique · trainer-selected repetitions

START / handles beside chest FINISH / controlled forward press

GRIP / CONTACT / Neutral handle grip. Palms face inward through this press; keep wrists aligned with forearms.

SETUP / Two secure rear anchors at chest-height level; one continuous band per handle.

MOVE / Press forward at chest height; keep hands shoulder-width apart.

RETURN / Return slowly; keep the same stance and comfortable shoulder range.

MAIN / RED

Pectoralis major: draws the upper arm forward and toward the chest midline.

SECONDARY / BLUE

Triceps extend the elbows; anterior deltoid assists the press.

SUPPORT / GREEN

Abdominals resist arching and rotation; hips and legs steady the split stance.

Standing mid-height band chest fly

Added band technique · trainer-selected repetitions

START / arms comfortably open FINISH / hands meet before chest

GRIP / CONTACT / Neutral handles / fly arc. Palms face forward with arms open and inward as the hands meet. Keep wrists aligned; follow the arm arc without a forced wrist twist.

SETUP / Two secure rear anchors at chest-height level; one continuous band per handle.

MOVE / Sweep both upper arms forward in a hugging arc; keep a soft elbow bend.

RETURN / Return slowly; keep the same stance and comfortable shoulder range.

MAIN / RED

Pectoralis major: draws the upper arm forward and toward the chest midline.

SECONDARY / BLUE

Anterior deltoid assists; shoulder-blade and rotator-cuff muscles guide the motion.

SUPPORT / GREEN

Abdominals resist arching and rotation; hips and legs steady the split stance.
