Exercise technique

Standing shared-handle overhead extension

8-12 controlled repetitions

START / handle behind head FINISH / handle overhead

GRIP / CONTACT / Two-hand shared grip. Both hands retain the shared attachment. Keep each wrist aligned; this is not two independent handles.

SETUP / Both hands share one handle; two tubes run to low rear.

MOVE / Extend both elbows to move the shared handle overhead.

RETURN / Bend both elbows; return the handle behind the head.

MAIN / RED

Triceps brachii extends both elbows as the shared handle moves overhead.

SECONDARY / BLUE

Shoulder muscles control upper-arm position; forearm muscles hold the shared grip.

SUPPORT / GREEN

Trunk and hip stabilizers maintain the standing posture. Both feet form the base in the illustrated version.

Technique study / Standing shared-handle overhead extension

SETUP / EQUIPMENT
Two pale elastic tubes connect a low rear rack point to one red handle held with both hands. This differs from using one independent handle in each hand.
START POSITION / SUPPORT
Stand with soft knees and a slight torso incline. Bring the upper arms beside the head and bend the elbows so the shared handle is behind the head.
WORKING MOVEMENT
Extend both elbows to move the shared handle overhead.
RANGE / CONTROLLED RETURN
Bend both elbows; return the handle behind the head.
FORM CHECKS
Keep the trunk steady, wrists aligned and the movement controlled.
EASIER OPTION
Use a smaller comfortable range and reduce band tension.
EXTERNAL PULL DIRECTION
Down/back toward the low rear anchor

Reading the muscle colours: Colour is qualitative surface projection, not measured muscle activation or exact tissue boundaries. Some regions are projected beneath clothing. Deep or occluded assistants are explained in the text; absence of a visible colour patch does not mean absence of muscular work.
