01

Supported single-arm chest press

Chest / 2 planned sets / 8-12 each side

START / handle beside chest FINISH / controlled press

GRIP / CONTACT / Neutral handle grip

SETUP / Stable box; rear anchor near chest height.

MOVE / Press forward without leaning or twisting.

RETURN / Stop before elbow lock; return within a comfortable arc.

MAIN / RED

Pectoralis major: moves the upper arm forward and across the chest.

SECONDARY / BLUE

Triceps extend the elbow; anterior deltoid assists. Scapular muscles guide the shoulder blade.

SUPPORT / GREEN

Trunk muscles resist rotation; the box and planted feet stabilize the pelvis and legs.

Technique study / Supported single-arm chest press

SETUP / EQUIPMENT
Use a stable non-rolling PLYOSOFT box and a secure anchor behind you near chest height. Keep the band beside the arm, away from the neck and face.
START POSITION / SUPPORT
Sit tall with both feet planted. Start with the handle beside the chest, neutral wrist and elbow below shoulder height. Let the shoulder blade move naturally.
WORKING MOVEMENT
Breathe out and press forward smoothly while keeping ribs and pelvis steady. Do not lean or twist to finish.
RANGE / CONTROLLED RETURN
Finish before the elbow locks; return only as far as the shoulder remains comfortable. Avoid a deep forced stretch behind the torso.
FORM CHECKS
If the ribs flare, shoulder pinches or trunk turns, shorten the range and lower the load.
EASIER OPTION
Use an unloaded press rehearsal or a comfortable wall press-up instead.
EXTERNAL PULL DIRECTION
Back toward the rear chest-height anchor

SECONDARY / BLUE

Forearm muscles steady the grip and wrist; shoulder muscles hold the upper arms beside the torso.

SUPPORT / GREEN

Technique study / Seated straight-bar pressdown

SETUP / EQUIPMENT
Use one secure high rack anchor, one rated pull line and a straight-bar attachment. Position a stable PLYOSOFT box so the line stays in front of the body.
START POSITION / SUPPORT
Plant both feet; sit tall. Keep upper arms beside the ribs and wrists in line with forearms. Choose a grip you can hold without strain.
WORKING MOVEMENT
Exhale and extend the elbows without pushing the shoulders down with body weight. Keep the upper arms nearly still.
RANGE / CONTROLLED RETURN
Stop short of snapping the elbows straight. Return gradually into comfortable elbow flexion without letting the bar rise toward the face.
FORM CHECKS
Avoid a rocking torso, bent wrists or moving the whole upper arm. Reduce load if the elbows or grip lose control.
EASIER OPTION
Rehearse the elbow motion unloaded or use a lighter single-handle variation matched to current tolerance.
