FULL BODY / DAYS 5–6

Days 5–6: full-body sessions

One set of session instructions. Use the resistance record beside each exercise; R1–R3 changes the equipment options, not the exercise page.

1 Read the shared protocol2 Follow the exercise steps3 Record your week

Starting settings: two sets for main exercises, one for supporting exercises, one easy set for control drills. Day 5 uses no more than two sets. Day 6 stays one easy set or rest. Read the protocol for effort, recovery and band selection.

DAY 5 / SESSION

Full body A / moderate

A modest whole-body session; no extra accessory finishers

Read each linked technique guide before starting. Warm up and rehearse unloaded; check the base, breathing and return.

  1. 1

    Supported sit-to-stand

    Main exercise2 sets6-10 repetitions

    Get into position

    Sit near the front with feet about hip-width apart, heels planted and knees following the toes. Use armrests for assistance if needed.

    See setup & four movement steps →
    Which muscles are working?Quadriceps and gluteus maximus raise the body from the chair.
  2. 2

    Seated single-leg band curl

    Supporting exercise1 set8-12 each side repetitions

    Get into position

    Sit tall with the working thigh supported. Start with that heel forward and the knee softly extended; keep the ankle comfortable.

    See setup & four movement steps →
    Which muscles are working?Hamstrings bend the knee, drawing the heel back.
  3. 3

    Supported single-arm chest press

    Main exercise2 sets8-12 each side repetitions

    Get into position

    Sit tall with both feet planted. Start with the handle beside the chest, neutral wrist and elbow below shoulder height. Let the shoulder blade move naturally.

    See setup & four movement steps →
    Which muscles are working?Pectoralis major: moves the upper arm forward and across the chest.
  4. 4

    Bench-supported one-arm row

    Main exercise2 sets8-12 each side repetitions

    Get into position

    Plant both feet in a comfortable stagger. Support the opposite palm under its shoulder. Incline from the hips; keep neck and trunk aligned, knees soft.

    See setup & four movement steps →
    Which muscles are working?Latissimus dorsi: draws the upper arm back toward the trunk.
  5. 5

    Seated brace with normal breathing

    Easy control1 set3 relaxed breaths per hold; 3 holds repetitions

    Get into position

    Sit comfortably tall with ribs over pelvis and both feet on the floor. Keep shoulders relaxed and avoid arching the back.

    See setup & four movement steps →
    Which muscles are working?Abdominal wall: develops gentle trunk stiffness while breathing.

Effort: about four more good repetitions still possible. Unloaded control drills stay easy; do not force fatigue. Rest 60-120 seconds, or longer as needed.
